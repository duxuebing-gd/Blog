## 11 课 · 一句话（学完填 ✓）

| Day | 模块 | 一句话（先背这个，细节以后补） | ✓ |
|-----|------|-------------------------------|---|
| D3 | 时态·状态(上) | **状态用 be，动作用实义动词；现在时 I 用原形，he/she 加 s** | ☐ |
| D4 | 时态·状态(下) | **过去 be→was/were，动词→过去式；将来 will + 原形** | ☐ |
| D5 | 被动语态 | **宾语变主语 + be + 过去分词：The book was read.** | ☐ |
| D6 | 非谓语 | **to do 目的/将来；doing 主动进行；done 被动完成** | ☐ |
| D7 | 句子成分 | **主谓宾表是骨架；定状补是修饰** | ☐ |
| D8 | 实义动词 | **有实际意义的动词：eat, run, make…** | ☐ |
| D9 | 动词分类 | **系动词接表语；情态后接原形；助动词帮构成时态/疑问** | ☐ |
| D10 | 三单 | **he/she/单数名词 → 动词 + s/es；I/you/复数用原形** | ☐ |
| D11 | -ing | **现在分词：进行、主动；动名词当名词用** | ☐ |
| D12 | -ed | **过去式 / 过去分词；规则 +ed，不规则需背** | ☐ |
| D13 | 名词所有格 | **'s 表所属：Tom's book；以 s 结尾可加 '** | ☐ |
